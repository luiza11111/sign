🆘 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

❌ Ошибка при входе ("Подтвердите действия...")
   → Backend не запущен
   → Откройте cmd, введите: cd server && npm start

❌ Пустой экран в браузере
   → Frontend не запущен
   → Откройте cmd, введите: npm run dev

❌ Не может подключиться к БД
   → PostgreSQL не запущена
   → Откройте Services и запустите PostgreSQL

❌ Порт занят ("EADDRINUSE")
   → Закройте предыдущие процессы Node.js

Подробнее → читайте ПОЛНОЕ_РУКОВОДСТВО.md
