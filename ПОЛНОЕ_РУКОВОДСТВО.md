## 📊 СТРУКТУРА ДАННЫХ

### База данных: PostgreSQL (БД: "sign")

#### Таблица: users
```
id          INTEGER (PRIMARY KEY)
name        TEXT
email       TEXT (UNIQUE)
password_hash  TEXT (bcrypt)
role        TEXT (admin, user)

```
id          INTEGER (PRIMARY KEY)

```
id          INTEGER (PRIMARY KEY)
user_id     INTEGER (FOREIGN KEY → users.id)
text        TEXT (исходный текст)
translation TEXT (перевод)
created_at  TIMESTAMP
```

## 🆘 РЕШЕНИЕ ПРОБЛЕМ

### ❌ "Подтвердите действия на localhost:5173" / "Ошибка при входе"

**Причина:** Backend не запущен или не отвечает

**Решение:**
```bash
1. Откройте новое cmd окно
2. Введите:
   cd C:\Users\HUAWEI\Documents\GitHub\sign\server
   npm start
3. Должно появиться: ✅ PostgreSQL қосылды!
```

**Если не помогает:**
- Проверьте что PostgreSQL запущена
- Проверьте что пароль в .env правильный: `DB_PASSWORD=luizok04`
- Перезапустите PostgreSQL

---

### ❌ Чистый экран, ничего не загружается

**Причина:** Frontend не запущен

**Решение:**
```bash
1. Откройте новое cmd окно
2. Введите:
   cd C:\Users\HUAWEI\Documents\GitHub\sign
   npm run dev
3. Должно появиться: ✅ VITE v5.0+ ready
```

---

### ❌ Ошибка "EADDRINUSE: Port already in use"

**Причина:** Порт занят другим процессом

**Решение Windows:**
```bash
# Найдите процесс на порту 3001
netstat -ano | findstr :3001

# Закройте его (замените PID на найденный номер)
taskkill /PID 12345 /F

# То же для порта 5173
netstat -ano | findstr :5173
taskkill /PID 12345 /F
```

---

### ❌ "Connection refused" / Не может подключиться к БД

**Причина:** PostgreSQL не запущена

**Решение:**
1. Откройте **Services** (services.msc)
2. Найдите **postgresql-x64-XX**
3. Нажмите **Start** (если остановлен)
4. Перезапустите Backend

**Или через pgAdmin:**
- Откройте http://localhost:5050
- Введите пароль
- Проверьте что сервер запущен

---

### ❌ Ошибка: "FATAL: Ident authentication failed for user postgres"

**Причина:** Неправильный пароль в .env

**Решение:**
```bash
1. Откройте файл: .env
2. Проверьте: DB_PASSWORD=luizok04  (должен совпадать с пароль PostgreSQL)
3. Если не совпадает - измените
4. Перезапустите Backend
```

---

### ❌ Регистрация не работает / Ошибка "Email уже существует"

**Решение:**
1. Используйте другой email
2. Или удалите пользователя из БД через pgAdmin/psql
3. Попробуйте снова

---

### ❌ Я забыл пароль админа

**Решение:** Пароль админа зафиксирован в коде
```bash
Email: admin@gmail.com
Пароль: admin123
```

Если не работает - удалите админа из БД и перезапустите Backend (создастся автоматически с тем же паролем).
